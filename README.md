# Арканоид — простая игра

**Авторы:** Рошинец Владислав Маратович и Калинкин Илья Дмитириевич  
**Группа:** ПИ25-1  
**Дисциплина:** Практикум по программированию

## Описание проекта

Классическая аркада «Арканоид» на `tkinter`. Игрок двигает платформу внизу экрана
и отбивает мяч, который разбивает кирпичи. Нужно разбить все кирпичи на трёх
уровнях и не уронить мяч.

## Функциональные возможности

### Основной функционал
-  Платформа двигается стрелками ← / → (или A / D) и мышью
-  Мяч отскакивает от стен, потолка, платформы и кирпичей
-  Кирпичи разбиваются, за каждый начисляются очки
-  Угол отскока зависит от того, куда мяч попал на платформе: краем можно направлять мяч
-  Три жизни: упавший мяч отнимает одну, без жизней — конец игры

### Дополнительный функционал
-  Три уровня с разными схемами кирпичей, на каждом следующем мяч быстрее
-  Серебряные кирпичи выдерживают два удара и темнеют после первого
-  Бонусы, которые иногда выпадают из кирпичей:
  - **E** — платформа становится в 1,5 раза шире
  - **S** — мяч замедляется
  - **♥** — лишняя жизнь
-  Рекорд за сессию на панели сверху
-  Пауза и перезапуск игры
-  Управление работает и в русской раскладке
-  Модульные тесты для логики игры

## Требования к системе

- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** только стандартные: `tkinter` (встроенная), `math`, `random`, `unittest`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/brrmaleey/arkanoid.git
cd arkanoid
```

### 2. Создание и активация виртуального окружения
Папка `venv/` уже лежит в репозитории (так требуется для проверки).
Если она не запускается на вашем компьютере, создайте её заново.

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
Сторонних библиотек нет, команда ничего не установит.

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
| Клавиша | Действие |
|---|---|
| **← / →** или **A / D** | двигать платформу |
| **Мышь** | платформа следует за курсором |
| **Пробел** или **клик** | запустить мяч |
| **P** или **Esc** | пауза |
| **R** | начать игру заново |

### 6. Запуск тестов
```bash
python -m unittest -v
```

**Назначение основных модулей:**
- `main.py` — точка входа в программу
- `app.py` — класс `App`: окно, холст, клавиатура, мышь и игровой цикл
- `game_objects.py` — классы объектов: общий `GameObject` и наследники `Paddle`, `Ball`, `Brick`, `Bonus`
- `game_model.py` — класс `GameModel`: правила игры, столкновения, очки, жизни, уровни и бонусы
- `levels.py` — схемы уровней в виде строк из букв
- `renderer.py` — класс `Renderer`: рисует кадр на холсте
- `test_model.py` — тесты для объектов и логики игры

Логика (модель) отделена от отрисовки, поэтому её можно тестировать без окна.
Объекты вынесены в отдельный модуль, чтобы `game_model.py` описывал только правила
игры, а уровни — в `levels.py`, чтобы новый уровень можно было добавить, не трогая код.
Папки `widgets/` из примерной структуры нет: слайдеров и кнопок в игре нет,
управление идёт с клавиатуры и мыши.

## Как это работает

1. `App.update()` вызывается каждые 16 мс (около 60 кадров в секунду) через `window.after()`.
2. Перед кадром платформа сдвигается по зажатым клавишам. Зажатые клавиши хранятся
   в множестве, поэтому платформа едет плавно, пока клавиша нажата.
3. `GameModel.step()` за один кадр:
   - двигает мяч сначала по x, потом по y. Если после шага по x мяч задел кирпич,
     удар пришёлся сбоку и разворачивается `dx`, если после шага по y — разворачивается `dy`;
   - при ударе о платформу считает смещение мяча от её центра (от -1 до 1),
     умножает на 60° и отправляет мяч вверх под этим углом к вертикали;
   - двигает бонусы и применяет те, что поймала платформа;
   - если мяч упал, отнимает жизнь, если кирпичей не осталось — загружает следующий уровень.
4. `Renderer.draw()` очищает холст и рисует панель счёта, кирпичи, бонусы, платформу,
   мяч и надпись для текущего состояния игры (старт, пауза, конец игры, победа).
5. Все объекты считаются прямоугольниками, поэтому столкновение любых двух проверяется
   одной формулой в `GameObject.overlaps()`.

## Пример использования
1. Запустите `python main.py` — откроется окно с первым уровнем и мячом на платформе.
2. Нажмите **пробел**, мяч полетит вверх.
